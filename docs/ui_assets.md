## 三、通用导出要求

| 项 | 要求 |
| --- | --- |
| 换算规则 | **给图像素宽 ≈ 显示 rpx 数 × 2~3**。hero/band 显示宽是满屏 750rpx → 给 1500px 起 |
| 比例 | **必须守住上表比例**。`widthFix` 下比例一变，页面高度跟着变，版式会塌 |
| 格式 | 水墨/照片类用 **JPG**（体积小）；图标/符号用 **PNG 透明底** |
| 体积 | 原稿 ≤3MB 随意给，我统一压到**单张 ≤150KB、全站图片合计 ≤800KB**（小程序主包 2MB 上限） |
| 水印 | **必须无平台/AI 水印**。上一版就是靠裁掉底部 10% 才干净；出图时把水印区避开或后期裁掉 |
| 透明底 | 图标类请确认在**纸白底 `#F7F6F3` 上可读**；不要给白底方图，会露白框 |
| 色彩 | 全站目标色板：纸白 `#F7F6F3` / 墨 `#16181A` / 朱砂 `#A6321F`。出图往这套靠最省事（详见 `docs/visual_system.md`） |
| 不要在图里排字 | 站名、标题、按钮文案都是代码渲染的文本（可搜索、可无障碍朗读）。图里再写一遍字会重复且换字要重做图 |

## 五、给我图之后我做什么

1. 裁水印 → 2. 按比例压缩转 JPG/PNG → 3. 落到 `miniprogram/images/` → 4. 改/加引用 →
5. 跑构建检查 + 提交推送。全过程你不用管技术细节。
