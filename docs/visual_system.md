# 名堂 · 视觉系统（山水泼墨）

> 2026-09-23 起生效。改视觉**只改 `miniprogram/app.wxss` 的令牌**，页面样式一律引用变量，
> 不写死颜色。本文档与 `app.wxss` 顶部注释互为对照。

## 一、为什么换

旧版走的是「米黄伪宣纸 + 青绿强调 + 楷体 + 阴影大圆角」的古风路线，实测问题：

| 旧做法 | 问题 |
| --- | --- |
| 底色 `#F4F0E7` / 卡片 `#FCFAF5` 米黄 | 显旧、显黄，像茶室宣传单，不是画境 |
| 强调色 `#5E7A73` 青绿 | 与米黄撞成「复古」色，抢主色 |
| 标题楷体 `Kaiti SC` | 系统楷体字重单一，偏「印章/牌匾」而非山水 |
| 卡片 `16rpx` 圆角 + `box-shadow` | 移动端卡片通用语言，与水墨留白相冲 |
| 五行用 Material 色（`#4CAF50`/`#2196F3`/`#FF5722`） | 与整体色系完全脱节 |
| 主页 4+3 张卡各挂一行小字 | 未上线功能与正式功能同级，卡面被解释文字占满 |

现改为 **山水泼墨**：泼墨山水打底 → 纸白留白承托内容 → 墨阶分层 → 朱砂极小点缀。

## 二、设计令牌（`app.wxss`）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F7F6F3` | 页面底色（纸白，非米黄） |
| `--paper-deep` | `#EFEDE8` | 次级底：chip 底、按下态、浅色块 |
| `--card` | `#FFFFFF` | 卡片面 |
| `--ink` | `#16181A` | 主文字 / 主行动按钮底 |
| `--ink-2` | `#4A4F55` | 次级文字 |
| `--ink-3` | `#8A9099` | 说明、标签、未选中 |
| `--line` | `#E4E2DD` | 细分割线（承托分层，替代阴影） |
| `--line-strong` | `#C9CDD2` | 描边 chip 边框 |
| `--cinnabar` | `#A6321F` | 朱砂：**仅**选中 / 主行动文字 / 印章 |
| `--cinnabar-bg` | `#FBF1EE` | 朱砂选中态的极淡底 |
| `--r-sm` | `3rpx` | 小圆角（chip、按钮） |
| `--r-md` | `6rpx` | 中圆角（卡片、感觉卡） |
| `--serif` | `Songti SC / STSong / Noto Serif SC` | 标题宋体（替代楷体） |

**墨阶是唯一的色彩层次**：`--ink`（最重，标题/主行动）→ `--ink-2`（正文）→ `--ink-3`（弱化）。
深浅不同不是"灰色变体"，是**视觉重量**分级。

## 三、四条硬规则

1. **朱砂只出现在三处**：选中态、主行动文案、印章。
   一旦朱砂被用作「好看的点缀」，它的语义就废了。
2. **不用阴影，用线**。分层靠 `--line` 细线 + 留白。全局已清空 `box-shadow`。
3. **圆角一律收敛**：卡片 `6rpx`、chip/按钮 `3rpx`。禁止 `16rpx` 以上与胶囊 `999rpx`。
4. **标题用宋体**（`.h1/.h2/.h3` 或 `var(--serif)`），正文保持无衬线。

## 四、主视觉素材

小程序 WXSS **不支持本地背景图**，主视觉必须用 `<image>` 标签层承载。

| 文件 | 尺寸 | 体积 | 用途 |
| --- | --- | --- | --- |
| `images/ink-hero.jpg` | 900×539 | ~66KB | 主页整幅泼墨主视觉（`mode="widthFix"`，图在上字在下的「诗堂」版式） |
| `images/ink-band.jpg` | 900×240 | ~42KB | 二级页窄幅页头（more / name / wizard / result） |

生成流程（如需重做）：
1. 用图像生成工具出泼墨山水；
2. **必须裁掉底部约 10% 的 AI 水印带**（`Pillow: crop((0, 0, W, int(H*0.90)))`）；
3. 压缩导出 JPEG，单张控制在 100KB 以内（主包体积限制）；
4. 删除原始大图，不留在仓库里。

## 五、页面版式

| 页面 | 版式 |
| --- | --- |
| `home` | 整幅 hero → 图下留白处居中站名（宋体 62rpx，字距 18rpx）→ 两张大功能卡 → 「更多功能 ›」朱砂文字链 |
| `more` | 窄幅 band → 分组标题（24rpx `--ink-3`）→ 细线分隔的行列表，禁用行文字用 `--ink-3` + 「即将上线」 |
| `name` / `wizard` | 窄幅 band → 页面标题 → 底部主行动按钮 |
| `result` | 窄幅 band → 内容区（`padding: 32rpx 40rpx`） |

**主页铁律**：主功能卡**不挂小字说明**。细分功能一律下沉到 `pages/more`。

## 六、五行色板（传统矿物色）

五行需要功能辨识度，但不能用 Material 色。改用与水墨同源的低饱和矿物色，白字压底：

| 五行 | 值 | 意象 |
| --- | --- | --- |
| 金 | `#8D7B4F` | 赭黄 |
| 木 | `#4E6B54` | 苍绿 |
| 水 | `#3E5A73` | 石青 |
| 火 | `#A6321F` | 朱砂 |
| 土 | `#7A6248` | 赭石 |

## 七、按钮

微信 `button` 自带 `::after` 描边与超大默认行高，会与细线体系打架，故在 `app.wxss` 统一重置：

```css
button::after { border: none; }
.btn-primary   { background: var(--ink); color: var(--paper); line-height: 1.5; }
.btn-secondary { background: transparent; border: 1rpx solid var(--line-strong); }
```
